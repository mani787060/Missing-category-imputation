# Project:- Missing Category Imputation
 
-> This project demonstrates how to handle missing categorical values by replacing them with a constant category (e.g., "Missing" or "Unknown").
-> Implemented using Scikit-learn’s SimpleImputer, this technique ensures consistent data handling without dropping rows.

## Highlights:-
 
-> Handles missing categorical features 
-> Uses constant imputation strategy
-> Comparison before vs. after imputation
-> Works well for datasets where missing categories hold meaning
 
## Libraries Used:-
 
-> pandas
-> numpy
-> sklearn
-> matplotlib

## Goal:-
 
-> To maintain categorical consistency while handling missing values effectively and preparing data for ML models.
